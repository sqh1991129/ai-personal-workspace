## 生产环境四大开发规矩

### 规矩一：坚持使用 `src` 布局 (Src Layout)

* **原则**：禁止直接将包放置在项目根目录下。
* **原因**：`src/` 结构能强制 Python 解释器在测试和运行代码时导入**已安装在环境中的包**，彻底消除开发环境中的隐式相对导入（Implicit Relative Imports）与测试冲突问题。

### 规矩二：所有 IO 接口定义强类型 Schema

* **原则**：所有 API 接口、数据库出入参及服务间调用必须使用 Pydantic 模型描述。
* **原因**：杜绝使用 raw `dict` 传递核心业务数据，确保类型安全、运行时校验以及自动化的文档生成。

### 规矩三：结构化日志输出

* **原则**：严禁在生产环境代码中使用原生的 `print()` 语句。
* **原因**：必须通过 `loguru` 或 `structlog` 等日志库统一格式，输出带有时间戳、日志级别及上下文信息的 JSON 格式日志，以便接入 ELK / Loki 等运维日志监控平台。

### 规矩四：单点入口 `__main__.py`

* **原则**：包的根目录下必须提供 `__main__.py` 模块。
* **原因**：保持所有组件可模块化启动，支持通过 `python -m my_project` 命令平滑运行，极大地简化 K8s / Docker 镜像中的入口配置与启动逻辑。

### 2. `src/my_project/core/config.py`

基于 `pydantic-settings` 的类型安全配置管理文件：

```python
from pydantic import Field
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    # 基础配置
    PROJECT_NAME: str = "My Enterprise App"
    ENVIRONMENT: str = Field(default="production", description="development/testing/production")
    DEBUG: bool = False

    # 数据库配置
    DATABASE_URL: str = Field(..., description="PostgreSQL 连接 URL")
    
    # 环境变量解析配置
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        case_sensitive=True,
        extra="ignore",
    )


# 单例模式导出配置实例
settings = Settings()

```

### 3. `Dockerfile`

基于多阶段构建（Multi-Stage Builds）与非 root 账号保障安全运行的生产级镜像配置：

```dockerfile
# ----------------------------------------------------
# 1. 构建阶段 (Build Stage)
# ----------------------------------------------------
FROM python:3.11-slim AS builder

ENV PYTHONUNBUFFERED=1 \
    PYTHONDONTWRITEBYTECODE=1 \
    PIP_NO_CACHE_DIR=off \
    PIP_DISABLE_PIP_VERSION_CHECK=on

WORKDIR /build

# 安装依赖构建工具
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

# 安装 poetry 并导出 requirements.txt
RUN pip install poetry
COPY pyproject.toml poetry.lock ./
RUN poetry export -f requirements.txt --output requirements.txt --without dev

# ----------------------------------------------------
# 2. 运行阶段 (Runner Stage)
# ----------------------------------------------------
FROM python:3.11-slim AS runner

ENV PYTHONUNBUFFERED=1 \
    PYTHONDONTWRITEBYTECODE=1 \
    TZ=Asia/Shanghai

WORKDIR /app

# 安装必要的运行时依赖（如 libpq 等）
RUN apt-get update && apt-get install -y --no-install-recommends \
    curl \
    && rm -rf /var/lib/apt/lists/*

# 从 builder 阶段复制依赖并安装
COPY --from=builder /build/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制应用程序代码
COPY src/ ./src/
COPY pyproject.toml .

# 创建非 root 账号保障生产环境运行安全
RUN useradd -m -u 1000 appuser && chown -R appuser:appuser /app
USER appuser

EXPOSE 8000

# 启动服务 (对应规矩四：模块化启动)
CMD ["python", "-m", "my_project"]

```
